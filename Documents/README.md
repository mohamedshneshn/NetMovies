# NetMovies - Documents Folder

This folder contains key documents and diagrams that outline the design and development of the **NetMovies** app. These files provide insights into the data model, system workflows, business requirements, and more. The documents in this folder are intended to guide the development process and ensure a clear understanding of the project.

## Contents:

### 1. **Data Model MindMap**

- A visual representation of the **data structure** for the NetMovies app. This mind map outlines the various objects, relationships, and key fields used within the app to track customer movie history, feedback, and recommendations.

### 2. **Swimlane Diagram**

- A diagram that illustrates the **workflow** of the NetMovies app, showing the interactions between different actors (such as customers, admins, and the system) and the steps involved in key processes like viewing movies, submitting feedback, and receiving recommendations.

### 3. **Business Requirements Document (BRD)**

- A detailed document that outlines the **business goals, user stories**, and functional requirements for the app. It includes the objectives of the project, the target audience, and the features needed to meet the needs of the users.
